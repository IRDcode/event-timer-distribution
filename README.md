# دانلود رسمی — استودیو تایمر رویداد

این ریپو **فقط محل انتشار فایل‌های نصب** برنامه‌ی استودیو تایمر رویداد است.
سورس‌کد اینجا منتشر نمی‌شود؛ توسعه در ریپوی خصوصی انجام می‌شود.

## دانلود

از بخش [Releases](../../releases) آخرین فایل `Event Timer Studio-<نسخه>-setup.exe` را بگیرید.

- نصب روی ویندوز ۱۰ یا ۱۱ (شصت‌وچهاربیتی) — هیچ پیش‌نیاز دیگری لازم نیست.
- برنامه کاملاً آفلاین است؛ هیچ داده‌ای از دستگاه شما خارج نمی‌شود.
- کلید فعال‌سازی را از صادرکننده دریافت کنید.
- پشتیبانی: irdkiyacode@gmail.com

## به‌روزرسانی

برنامه‌ی نصب‌شده در هر باز شدن (در صورت اتصال اینترنت) همین صفحه را بررسی می‌کند؛
اگر نسخه‌ی تازه‌تری منتشر شده باشد، در نوار پایین برنامه دکمه‌ی «نسخه‌ی تازه آماده است» می‌آید.
